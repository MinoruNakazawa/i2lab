# i2lab

[中沢研究室 Webサイト](https://minorunakazawa.github.io/i2lab/)

- [訪問数ダッシュボード（日・週・月のグラフとCSV）](https://github.com/MinoruNakazawa/i2lab/tree/analytics)
- [集計の実行履歴](https://github.com/MinoruNakazawa/i2lab/actions/workflows/site-analytics.yml)
- [設定・運用手順](https://github.com/MinoruNakazawa/i2lab/blob/gh-pages/docs/analytics/README.md)

サイト本体は `gh-pages`、訪問数ログは初回集計成功後の `analytics` ブランチです。
この既定ブランチには、毎日の自動集計を起動するワークフローを置いています。
